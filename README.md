26fallAI — Experiment 1: Text Classification

# 人工智能 · 实验一：文本分类

## 一、实验简介

本实验针对文本分类任务，使用 TF-IDF 将文本转换为数值特征，分别训练支持向量机（SVM）、逻辑回归（Logistic Regression）、朴素贝叶斯（Naive Bayes）和多层感知机（MLP）模型，并通过验证集比较不同算法及参数设置下的分类性能。

在此基础上，本实验进一步比较了原始文本与清洗部分邮件头字段后的分类效果，并使用验证集表现较好的模型对无标签测试集进行预测。

## 二、数据集

- 有标签数据：7,368 条，包含 `text` 和 `target` 两列。
- 无标签测试数据：2,457 条，包含文本数据。
- 分类任务：十分类任务，标签为 0–9。

实验使用 `train_test_split` 将有标签数据按照 8:2 的比例划分为训练集和验证集，并设置 `random_state=42`、`stratify=y`，以保证实验划分可复现并维持各类别比例。

训练集用于拟合 TF-IDF 特征提取器和分类模型，验证集用于评估模型表现。无标签测试集不参与模型选择，最终模型在全部有标签数据上重新训练后生成预测结果。

## 三、实验方法

### 1. 文本特征提取

使用 `TfidfVectorizer(max_features=5000)` 提取文本特征，最多保留 5,000 个特征。验证集和测试集均使用在对应训练数据上拟合的特征提取器进行转换。

### 2. 分类算法与参数比较

- **支持向量机（SVM）**：使用线性核，比较 `C = 0.1、1、10、100`。
- **逻辑回归**：比较 `C = 0.1、1、10、100`，最大迭代次数为 1,000。
- **朴素贝叶斯**：使用默认参数的 `MultinomialNB`。
- **多层感知机（MLP）**：设置一个包含 100 个神经元的隐藏层，使用 ReLU 激活函数和 Adam 优化器，最大迭代次数为 30，并记录训练损失曲线。

模型评价指标为 Accuracy 和 Macro-F1。其中，Macro-F1 对各类别分别计算 F1 分数后取算术平均，可用于观察模型在不同类别上的整体表现。

### 3. 文本清洗对照实验

在保持训练集、验证集划分和分类算法不变的情况下，去除邮件文本中的部分字段：`From`、`Organization`、`Lines`、`Reply-To` 和 `NNTP-Posting-Host`，保留 `Subject` 及正文。

使用清洗后的文本重新拟合 TF-IDF，并以 `C=100` 的逻辑回归进行分类，与原始文本结果比较。

## 四、实验结果

| 方法 | 参数设置 | Accuracy | Macro-F1 |
|---|---|---:|---:|
| SVM | C=0.1 | 0.8134 | 0.8225 |
| SVM | C=1 | 0.9030 | 0.9040 |
| SVM | C=10 | 0.9077 | 0.9085 |
| SVM | C=100 | 0.9104 | 0.9112 |
| 逻辑回归 | C=0.1 | 0.8433 | 0.8447 |
| 逻辑回归 | C=1 | 0.8976 | 0.8985 |
| 逻辑回归 | C=10 | 0.9132 | 0.9135 |
| 逻辑回归 | C=100 | 0.9159 | 0.9162 |
| 朴素贝叶斯 | 默认参数 | 0.8860 | 0.8867 |
| MLP | 隐藏层 100，最大迭代 30 | 0.9152 | 0.9158 |
| 清洗文本 + 逻辑回归 | C=100 | 0.9166 | 0.9169 |

在本次实验中，清洗文本后的逻辑回归模型取得了最高的验证集 Accuracy（0.9166）和 Macro-F1（0.9169）。相较于原始文本下的逻辑回归模型（C=100），Macro-F1 提高了 0.0007，说明本次清洗带来的性能变化较小，尚不足以证明去除这些邮件头字段能够普遍提升分类效果。

MLP 在 30 次迭代后达到预设迭代上限，训练过程中出现未收敛警告，因此其结果应结合损失曲线谨慎解读。

### 4. 邮件头字段消融实验

为进一步分析邮件头信息对文本分类性能的影响，本实验固定训练集与验证集划分、TF-IDF 最大特征数（5000）及逻辑回归参数（C=100），分别删除单个邮件头字段，并与原始文本基线及同时删除全部五个字段的设置进行比较。

| 实验设置 | Accuracy | Macro-F1 |
|---|---:|---:|
| 不删除（基线） | 0.9159 | 0.9162 |
| 删除 From | 0.9172 | 0.9177 |
| 删除 Organization | 0.9132 | 0.9136 |
| 删除 Lines | 0.9152 | 0.9154 |
| 删除 Reply-To | 0.9138 | 0.9142 |
| 删除 NNTP-Posting-Host | 0.9186 | 0.9188 |
| 删除全部五个字段 | 0.9166 | 0.9169 |

**结果分析：**

- 删除 `NNTP-Posting-Host` 后，Macro-F1 达到 0.9188，是本组实验中的最佳结果。
- 删除 `Organization` 和 `Reply-To` 后，Macro-F1 分别下降至 0.9136 和 0.9142，说明不同邮件头字段对分类可能具有不同作用。
- 删除全部五个字段后的 Macro-F1 为 0.9169，低于仅删除 `NNTP-Posting-Host` 的结果。

实验说明，邮件头字段不应被一概视为噪声，有针对性的文本预处理可能比无差别删除更多信息更有效。由于本实验仅采用一次固定的数据划分，且指标变化较小，尚不能判断这些差异是否具有统计显著性。

本次消融实验中，仅删除 NNTP-Posting-Host 的设置取得了更高的验证集指标，但最终模型仍采用预先设定的五字段清洗方案。若要进一步优化模型，可将该单字段清洗方案作为候选方案，在独立测试或交叉验证中继续评估。

实验结果文件：`ablation_results.csv`。

## 五、最终预测

根据验证集结果，选择清洗文本后的逻辑回归模型（`C=100`）作为最终模型。在全部 7,368 条有标签数据上重新拟合 TF-IDF 和逻辑回归模型，再对 2,457 条无标签测试数据进行预测。

最终预测文件为 `predictions.csv`，包含一列 `target`，每行对应一条测试数据的预测类别。

## 六、文件说明

- `ai_experiment_1.py`：完整实验代码，包含模型比较、文本清洗、消融实验和最终预测。
- `predictions.csv`：无标签测试集的预测结果。
- `ablation_results.csv`：邮件头字段消融实验的指标结果。
- `mlp_loss_curve.png`：MLP 训练损失曲线。

## 七、运行环境与方法

**主要依赖：** Python、pandas、scikit-learn、matplotlib。

安装依赖：

```bash
pip install pandas scikit-learn matplotlib
```

将 `ai_experiment_1.py`、`train_data.csv` 和 `test_data_unlabeled.csv` 放在同一目录下，在该目录中运行：

```bash
python ai_experiment_1.py
```

程序将输出各模型的验证集指标，并生成 `mlp_loss_curve.png`、`predictions.csv` 和 `ablation_results.csv`。

注意：运行前需确认两个数据文件已放置在代码所使用的相对路径下。如果数据集未上传至 GitHub，运行者需要另行获取数据文件。
